## 🎯 About This Repository

This repository serves as a personal knowledge base and code vault. Every concept includes:
* **`README.md`**: Theoretical explanation of the concept.
* **`Code`**: Clean, well-commented Java programs demonstrating the concept.
* **`Projects`**: Mini-projects applying the learned skills.

## 🚀 Curriculum Structure

### Phase 1: The Basics
The foundation of programming in Java.
- [x] Hello World & JVM Architecture
- [x] Data Types, Variables, and Type Casting
- [x] Operators (Arithmetic, Logical, Bitwise)
- [x] Control Flow (If-Else, Switch)
- [x] Loops (For, While, Do-While)
- [x] Methods & Method Overloading
- [x] 1D and 2D Arrays

### Phase 2: Core Java & OOPS
Building robust applications using Object-Oriented principles.
- [ ] Classes & Objects
- [ ] Constructors (Default, Parameterized, Copy)
- [ ] The 4 Pillars: Encapsulation, Inheritance, Polymorphism, Abstraction
- [ ] Interfaces & Abstract Classes
- [ ] Exception Handling (`try-catch`, `throw`, `throws`, Custom Exceptions)
- [ ] Strings, StringBuilder, and StringBuffer

### Phase 3: Data Structures & Algorithms
Translating problem-solving skills into efficient Java code.
- [ ] Big O Notation & Time/Space Complexity
- [ ] Lists (ArrayList, LinkedList)
- [ ] Stacks & Queues
- [ ] Trees (Binary Trees, BST, AVL)
- [ ] Hashing (HashMap, HashSet)
- [ ] Sorting Algorithms (Merge, Quick, Insertion)
- [ ] Graph Traversals (BFS, DFS)

### Phase 4: Advanced Java
Deep dive into modern Java capabilities and performance.
- [ ] Java Collections Framework (Deep Dive)
- [ ] Generics & Type Erasure
- [ ] Multithreading & Concurrency (`Thread`, `Runnable`, `Executors`, Locks)
- [ ] File I/O (NIO.2, Serialization)
- [ ] Java 8+ Features (Lambda Expressions, Stream API, Optional)
- [ ] Memory Management & Garbage Collection

### Phase 5: The Ultimate End (Enterprise)
Professional-grade development, architectural patterns, and frameworks.
- [ ] Creational, Structural, and Behavioral Design Patterns
- [ ] Unit Testing with JUnit 5 & Mockito
- [ ] Database Connectivity (JDBC & Hibernate/JPA)
- [ ] Spring Boot Basics (Dependency Injection, REST APIs)
- [ ] Microservices Architecture Overview
- [ ] Dockerizing a Java Application
